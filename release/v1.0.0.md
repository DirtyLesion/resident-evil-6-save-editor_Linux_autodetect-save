# RE6 Save Editor v1.0.0

This release publishes the existing portable Windows build together with a native Linux x86_64 AppImage.

## Assets

- **Windows:** `RE6SaveEditor-v1.0.0-win64.zip`
- **Linux:** `RE6SaveEditor-v1.0.0-x86_64.AppImage`

The Linux application uses Qt 6 and does not require Wine. The automated build tests the save-file code, verifies AppImage extraction, checks the bundled X11 and Wayland platform plugins, and smoke-tests startup in CI. A physical CachyOS/Wayland desktop session has not been independently verified.

## Save-file safety

- Intended for unencrypted Resident Evil 6 PC/Steam `savedata.bin` files. Console and encrypted saves are not supported.
- The editor recalculates the save checksum and creates a `.bak` backup when saving an existing file for the first time in a session.
- Back up your game save separately before making edits.
- Personal save files are user data and are intentionally not included in this release or the public source tree.
- The default CI suite uses synthetic test data. The additional real-save regression can be run locally with `-DRE6_SAVE_FIXTURE=/absolute/path/to/savedata.bin`.
