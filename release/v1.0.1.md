# RE6 Save Editor v1.0.1

This update improves the native Linux AppImage's first-run experience by detecting likely Resident Evil 6 PC/Steam saves and pre-filling their path in the existing Open dialog.

## Linux change

- Looks under common Steam userdata locations for app ID `221040`, including standard Steam installs and Flatpak Steam.
- Supports `XDG_DATA_HOME` and an explicitly configured `STEAM_DIR`.
- If multiple saves are found, preselects the most recently modified candidate and reports how many were found. The user still confirms the selected path or browses to another file.
- If no candidate is found, the standard file picker remains available for manual selection.

The detector tests use synthetic files and temporary directories. No personal `savedata.bin` file is included in the repository or release.

The existing Windows package remains available from the [v1.0.0 release](https://github.com/DirtyLesion/resident-evil-6-save-editor/releases/tag/v1.0.0); the Windows application is unchanged in v1.0.1.
